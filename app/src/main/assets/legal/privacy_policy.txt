欢迎使用应用加密计算器（以下简称“本应用”）。

我们重视您的个人信息及隐私安全，并依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》等法律法规处理和保护您的个人信息。

请您在使用本应用前仔细阅读本政策。若您不同意本政策，仍可选择使用基本计算器功能。

您也可以通过应用内的《个人信息收集清单》《已收集个人信息清单》《第三方 SDK 目录》《与第三方共享个人信息清单》及《应用权限说明》了解相关信息处理规则。

一、适用范围

本政策适用于本应用提供的计算器、隐私空间、应用管理、应用自定义、应用锁、私密相册、免费试用、微信登录、会员购买及相关服务。

基本计算器功能无需登录即可使用。计算器输入内容仅用于完成计算，不会上传至我们的服务器。

隐私空间密码与微信登录账号相互独立。微信登录不能替代隐私空间密码验证。

本应用不提供私密媒体云同步、云端备份或在线密码找回服务。

二、我们如何收集和使用个人信息

我们遵循合法、正当、必要和诚信原则，仅在提供相关功能所需的范围内处理个人信息。

1. 隐私授权及密码信息

我们在本机保存您的隐私授权状态、协议版本及同意时间，用于记录您的授权选择。

当您创建或修改隐私空间密码时，本应用将在本机保存必要的密码验证信息，用于身份验证及隐私空间保护。

为支持忘记密码时的恢复，本机保存经设备密钥（Android Keystore）加密的密码恢复材料；该材料仅用于在计算器页面恢复密码，不上传服务器，卸载或清除应用数据即删除。

2. 应用管理、应用自定义及应用锁

当您使用相关功能时，本应用会读取具有桌面启动入口的应用名称、包名、图标及可用状态，用于展示和管理应用列表。

对于您主动选择的应用，本应用会在本机保存应用名称、包名、排序、最近打开时间及次数、自定义名称、图标配置、快捷入口及应用锁状态等必要信息。

完整应用扫描结果仅用于当次列表展示，不会整体持久化或上传至服务器。

当您开启应用锁并授予相关权限后，本应用通过使用情况访问权限读取近期应用使用事件、包名及必要的最近使用时间，以识别当前前台应用。

系统返回的信息可能涉及未设置应用锁的其他应用。本应用仅在本机判断当前应用是否属于您的保护列表，不保存完整应用使用历史，不读取其他应用的聊天内容、界面文本或密码输入。

应用锁通过前台服务持续识别前台应用，并在需要时通过悬浮窗展示密码验证界面。当前版本不使用无障碍服务。

上述应用管理、应用自定义及应用锁业务信息不会上传至我们的服务器。

3. 私密相册

当您主动选择导入图片或视频时，本应用会读取您选择的文件，并将副本保存至应用私有目录。

为提供媒体管理功能，本应用会在本机保存文件名称、类型、大小、存储路径、缩略图路径、原始文件引用、尺寸、导入时间及文件夹等必要信息。

私密图片和视频可能包含敏感个人信息。相关信息仅用于您主动使用的导入、查看、管理、删除及恢复功能。未经必要授权，我们不会处理相关内容。

除非您主动选择移除系统相册中的原文件并完成系统确认，否则本应用不会主动删除原文件。

私密媒体及相关管理信息不会上传至我们的服务器，也不会通过微信账号进行云端同步。

4. 设备标识及免费试用

为提供设备免费试用、核验试用资格及防止重复领取试用权益，在您同意本政策后，本应用会在试用核验场景读取设备的 Android ID，并通过网络发送至我们的服务器。

服务器对设备标识进行 HMAC-SHA256 处理，仅在业务数据库中保存处理后的设备标识及试用时间记录，不保存原始 Android ID。

免费试用以设备为单位发放，具体试用时长以激活试用时的页面展示为准。首次激活需要联网核验。

网络不可用时，本应用可依据已确认的本地试用记录判断剩余试用时间，并在恢复联网后进行必要核验。

Android ID 可能因设备、系统用户、应用签名或系统状态变化而改变。

设备试用信息仅用于试用资格及有效期管理，不用于个性化广告推荐。

您未同意本政策时，本应用不会为试用核验上传 Android ID。

5. 微信登录及账号管理

当您主动选择微信登录时，本应用通过微信开放平台提供的授权能力完成登录。

为建立账号、识别身份及维持登录状态，我们会处理以下信息：

- 微信一次性授权凭证；
- 微信 OpenID、UnionID（如微信返回）；
- 应用内部账号标识；
- 账号创建时间及账号状态；
- 登录会话凭证及有效期。

本机通过加密机制保护登录会话凭证，服务器保存用于验证会话的凭证哈希及有效期等必要信息。登录会话默认有效期为7天。

本应用不通过微信登录获取您的微信昵称、头像、手机号码、聊天记录、通讯录或微信支付密码。

微信登录为可选择功能。您可以暂不登录，继续使用不要求账号登录的功能。

6. 会员权益

当您购买会员、查询会员状态或恢复会员权益时，我们会处理应用账号标识、会员类型、会员生效时间、到期时间、权益状态及相关发放、撤销记录。

上述信息用于提供会员服务及核验会员资格。

会员权益与应用账号关联。更换设备或重新安装应用后，可以通过原微信账号登录恢复仍然有效的会员权益。

会员权益恢复不包含私密相册、应用锁配置、自定义快捷入口配置及隐私空间密码等本地数据的同步。

7. 支付及交易信息

当您购买会员时，本应用通过悦森收银台提供微信支付、支付宝等支付方式。

为创建订单、确认付款结果、发放会员权益及处理异常交易，我们会处理订单编号、购买套餐、交易金额、支付渠道、支付状态、交易时间及第三方交易编号等信息。

本应用还会保存必要的订单状态变更、支付结果通知及交易核验记录。

我们通过第三方支付页面完成付款。本应用业务页面不要求您提供银行卡号或支付密码。

本应用会员套餐为一次性付费，不会自动续费或自动扣款。

有关会员服务、支付及退款的详细规则，请查阅《会员服务协议》。

8. 应用统计信息

在您同意本政策后，本应用通过友盟统计 SDK 进行应用使用情况统计及产品体验分析。

可能处理的信息包括：

- Android ID、OAID、OpenUDID、GUID 等设备标识；
- 设备品牌、型号、操作系统版本、语言、时区及屏幕参数；
- IP 地址、网络类型及网络连接状态；
- 应用版本、启动时间、使用会话及功能操作事件。

实际处理的信息与设备、系统及 SDK 配置有关。

本应用主动发送的统计事件不包含计算器密码、计算器输入内容、被保护应用的包名、私密媒体内容或文件夹名称。

9. 异常诊断信息

在您同意本政策后，本应用通过腾讯 Bugly SDK 进行异常诊断及稳定性分析。

可能处理的信息包括应用异常类型、崩溃堆栈、发生时间、进程及线程信息、应用版本、设备型号、系统版本、内存、存储及网络环境等诊断信息。

我们不会主动向异常诊断服务附加您的密码、私密媒体内容、被保护应用信息或私密文件路径等业务信息。

10. 网络及客服信息

当您使用联网功能时，我们会处理提供相关服务所必要的网络请求信息，包括用于网络通信、接口限流或支付通知处理的 IP 地址。

当您主动联系客服时，我们可能处理您提供的联系邮箱、问题说明、订单信息及必要的身份核验信息，用于处理咨询、投诉及售后请求。

三、权限及系统能力

本应用根据您实际使用的功能使用相应权限及系统能力，包括：

1. 网络访问：用于试用核验、账号登录、会员查询、支付及统计和异常诊断服务。
2. 网络及 Wi-Fi 状态：用于判断网络连接情况。
3. 使用情况访问：用于应用锁识别前台应用。
4. 显示在其他应用上层：用于展示应用锁密码验证界面。
5. 前台服务：用于维持应用锁保护功能。
6. 通知权限：用于展示应用锁服务状态通知。
7. 媒体选择及必要的存储权限：用于私密图片、视频的导入及恢复。
8. 应用可见性：用于展示可供您选择和管理的应用。

本应用不因设备试用而申请 IMEI、MAC 地址或设备序列号等受限制硬件标识的访问权限。

您可以通过系统设置管理或撤回相关权限。拒绝相关权限可能影响对应功能，但不影响不依赖该权限的基本计算器功能。

具体权限及使用场景请查阅《应用权限说明》。

本应用接入以下第三方服务：

- 友盟统计 SDK：用于应用使用情况统计；
- 腾讯 Bugly SDK：用于应用异常诊断；
- 微信 OpenSDK：用于微信授权登录；
- 悦森收银台：用于会员购买及支付处理；
- 微信支付、支付宝：用于相应支付渠道服务；
- 阿里云服务器服务：用于提供服务端运行及业务数据存储所需的基础设施。

具体服务提供方、信息种类、处理目的、处理方式及隐私政策，请查阅《第三方 SDK 目录》及《与第三方共享个人信息清单》。

我们不会出售您的个人信息，也不会向与服务无关的第三方提供您的个人信息。

对于依法需要取得单独同意的信息共享或敏感个人信息处理，我们将依法取得相应同意。

对于委托处理个人信息的服务提供方，我们将依法明确其处理范围及安全保护义务。

如因合并、分立、解散等情形需要转让个人信息，我们将依法履行告知及相关保护义务。

除法律法规规定或依法取得必要同意的情形外，我们不会公开披露您的个人信息。

五、个人信息的存储及保存期限

1. 本地信息

隐私空间密码验证信息、私密媒体、应用管理记录、自定义快捷入口配置及应用锁配置等主要保存在当前设备中，通常保存至您主动删除相关数据、清除应用数据或卸载应用时。

本机登录信息及会员缓存将在退出登录、注销账号等相应场景下清除。

2. 服务端信息

服务器保存提供试用、账号、会员及交易服务所必要的信息。

- 账号及微信绑定信息：在账号存续期间保存，注销后依法删除；依法需要保留的最小关联信息除外。
- 登录会话信息：用于登录状态验证，在会话有效期及必要的安全管理期限内保存。
- 设备试用记录：在核验试用资格及防止重复领取所必要的期限内保存，不因退出登录或账号注销而重新发放试用。
- 会员权益信息：在提供会员服务及处理相关请求所必要的期限内保存。
- 支付及交易记录：按照适用法律法规规定及处理交易、售后、争议所必要的期限保存。

对于达到删除条件的信息，我们将依法删除或匿名化处理。依法必须保留或因技术原因暂时难以删除的信息，将按照法律规定限制处理。

3. 存储地点及第三方信息

本地业务数据保存在您的设备中。我们的业务服务器部署于中华人民共和国境内的阿里云成都地域。联网业务信息由我们的服务端及相关服务提供方按照各自的业务范围和适用规则处理。

我们不会主动安排将您的个人信息传输至中华人民共和国境外。如确需进行跨境提供，将依法履行相关义务。

六、个人信息安全保护

我们根据实际处理风险采取相应的技术和管理措施，包括：

- 应用私有目录及系统沙箱隔离；
- 密码验证信息的安全保护；
- 本地会话凭证及必要业务信息加密；
- 服务端设备标识哈希处理；
- 登录鉴权、访问控制及业务数据隔离；
- 限制不必要的个人信息收集和上传。

任何安全措施均无法保证绝对安全。如发生或可能发生个人信息泄露、篡改或丢失，我们将依法采取补救措施，并履行相关通知及报告义务。

请妥善保管您的设备及隐私空间密码。

本应用不提供私密相册云端备份。卸载应用、清除应用数据、设备损坏或遗失等情况，可能导致本地私密数据无法恢复。

七、您的个人信息权利

您依法享有查阅、复制、更正、补充、删除个人信息、限制或拒绝处理，以及撤回同意等权利。

1. 本地信息管理

您可以通过应用内相关功能管理及删除私密媒体、应用管理记录、应用锁配置及自定义快捷入口配置。

您也可以通过系统设置管理权限、清除应用数据或卸载应用。

卸载应用或清除应用数据不会自动删除服务器已经保存的账号、试用及交易记录。

2. 退出登录

您可以通过应用内设置退出微信登录。

退出登录后，当前设备将停止使用该账号的会员权益，并按照设备剩余试用时间及免费功能规则提供服务。

退出登录不等于注销账号，也不会删除本机隐私数据。

3. 撤回隐私同意

您可以通过「设置—隐私协议」中的撤回同意入口撤回隐私授权。

撤回后，本应用将停止基于该授权继续主动处理个人信息及调用相关第三方服务，并限制需要隐私授权的功能。

您仍可使用基本计算器功能。

撤回同意不影响撤回前基于有效同意进行的信息处理活动，也不等于自动删除历史个人信息或注销账号。

已初始化第三方 SDK 的停止处理情况可能受到其运行机制影响。如您对相关处理存在疑问，可联系我们依法处理。

4. 账号注销

您可以通过「设置—安全—注销账号」申请注销本应用账号。

账号注销成功后：

- 删除原账号的微信绑定信息及登录会话；
- 停用原账号，清除有效会员权益及本地账号、会员缓存；
- 对依法需要留存的交易记录及必要关联信息进行限制处理；
- 保留设备原有试用记录，不重新发放试用资格；
- 保留本机私密相册、应用锁配置、自定义快捷入口配置及隐私空间密码。

注销后再次使用同一微信登录，将作为新账号使用，原账号会员权益不可恢复。

账号注销不等于注销您的微信账号。

有关会员权益终止及异常订单处理规则，请查阅《会员服务协议》。

普通隐私授权不能替代依法需要取得的监护人同意。

如监护人不同意相关个人信息处理，儿童仍可使用基本计算器功能。

监护人可以通过客服邮箱了解儿童个人信息处理情况，提出撤回同意、删除信息、账号注销及异常消费退款等申请。

具体规则请查阅《儿童个人信息保护规则》。
