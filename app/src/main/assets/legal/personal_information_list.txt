## 一、清单说明

本清单用于说明“应用加密计算器”在提供功能和服务过程中处理的个人信息种类、处理目的、处理方式、存储位置及必要性。

本清单与《应用加密计算器隐私政策》共同构成个人信息处理说明。具体功能是否启用，以你实际使用的应用版本为准。

我们遵循最小必要原则，不因使用计算器基础功能而要求你登录微信账号、开启应用锁权限或上传私密媒体。

## 二、本应用自行处理的个人信息

### 1. 隐私协议同意记录

- **信息内容：** 隐私政策同意状态、协议版本、同意时间。
- **处理目的：** 记录用户隐私选择，管理相关功能及 SDK 的初始化条件。
- **处理方式：** 在用户作出选择后记录和读取。
- **存储位置：** 应用本地专属存储。
- **是否必要：** 用于记录用户选择；不同意隐私政策时可退出应用。
- **是否上传：** 不因记录同意状态而主动上传至业务服务器。

### 2. 计算器隐私空间密码信息

- **信息内容：** 密码哈希、随机盐值、哈希算法参数、密码配置状态及创建或更新时间。
- **处理目的：** 创建、验证和修改隐私空间密码。
- **处理方式：** 在本地计算和验证，不保存明文密码。
- **存储位置：** 应用本地专属存储。
- **是否必要：** 使用密码保护的隐私空间时需要。
- **是否上传：** 不上传。
- **敏感性说明：** 相关验证材料一旦泄露可能影响个人隐私安全，我们采取必要保护措施。

计算器输入的算式和计算结果仅用于当前计算过程，不作为长期业务记录保存，也不会上传至服务器。

### 3. 已安装应用及应用管理信息

- **信息内容：** 具有桌面启动入口的应用名称、包名、图标、可用状态；用户主动选择的应用名称快照、包名、排序、最近打开时间和次数等。
- **处理目的：** 展示可选应用列表、管理私密应用入口、启动指定应用。
- **处理方式：** 读取符合系统查询条件的应用信息；仅持久化用户主动选择的必要配置。
- **存储位置：** 当前设备本地。
- **是否必要：** 使用应用管理或应用伪装功能时需要。
- **是否上传：** 不上传完整应用列表或用户选择的目标应用信息。

### 4. 应用伪装及应用锁配置

- **信息内容：** 伪装名称、内置图标配置、快捷入口状态、受保护应用包名、应用锁开关及必要的保护配置。
- **处理目的：** 创建伪装快捷入口，识别受保护应用并执行密码验证。
- **处理方式：** 本地保存配置；在应用锁运行期间按需判断前台应用状态。
- **存储位置：** 当前设备本地。
- **是否必要：** 使用对应功能时需要。
- **是否上传：** 不上传。

应用锁可能使用 Android 无障碍服务、悬浮窗及实际版本所需的其他系统能力。无障碍服务仅用于实现受保护应用的前台状态识别及验证界面触发，不用于读取聊天内容、密码输入或其他无关屏幕内容。

### 5. 私密相册信息

- **信息内容：** 用户主动选择的图片、视频及其文件名称、类型、大小、私有路径、缩略图路径、原始内容 URI、宽高、导入时间、所属文件夹等。
- **处理目的：** 导入、保存、查看、整理、删除和恢复私密媒体。
- **处理方式：** 通过系统文件或媒体选择器读取用户选定的文件，复制至应用私有目录并建立本地索引。
- **存储位置：** 当前设备本地。
- **是否必要：** 使用私密相册功能时需要。
- **是否上传：** 不上传。
- **敏感性说明：** 私密媒体及其管理信息可能属于敏感个人信息。

未经你主动选择并完成系统要求的确认，本应用不会删除系统相册中的原始文件。

### 6. 72 小时免费试用信息

- **信息内容：** 本地首次使用时间、试用开始时间、到期时间、试用状态、必要的时间校验记录，以及 Android ID（SSAID）。
- **处理目的：** 提供每台设备一次的连续 72 小时试用、校验有效期、减少重复领取。
- **处理方式：** 本地记录试用状态；在用户同意隐私政策且联网校验功能启用后，读取 Android ID 并通过安全网络连接发送至服务器。
- **存储位置：** 本地试用记录保存在当前设备；服务器保存经过 HMAC-SHA256 处理的设备标识摘要及必要的试用记录。
- **是否必要：** 本地试用记录用于提供免费试用；设备标识联网校验用于服务端试用资格管理。
- **是否上传：** 联网校验启用时可能上传原始 Android ID 用于服务器处理；业务数据库不保存原始 Android ID。
- **使用限制：** 不用于广告个性化推荐，不用于读取私密媒体或应用锁配置。

Android ID 属于可用于识别或关联设备的信息。即使服务器保存的是摘要，也不意味着该信息必然属于匿名信息。

### 7. 微信登录与账号信息

- **信息内容：** 微信授权返回的一次性授权凭证、微信开放平台提供的必要账号标识（如 OpenID）、应用内部用户 ID、账号关联关系、登录会话凭证及有效期信息。
- **处理目的：** 完成微信身份验证、建立账号、维持登录状态、恢复账号会员权益。
- **处理方式：** 用户主动授权后向服务器提交授权凭证；服务器完成身份验证并建立会话；本地加密保存必要会话凭证。
- **存储位置：** 当前设备及我们的业务服务器。
- **是否必要：** 使用微信账号登录及账号会员权益恢复时需要。
- **是否上传：** 上传完成登录和会话验证所需的信息。

我们不会因微信登录自动收集微信聊天记录、通讯录、微信支付密码或本地私密媒体。

### 8. 会员权益信息

- **信息内容：** 应用内用户 ID、会员套餐类型、权益来源、开通时间、到期时间、会员状态、权益发放及撤销记录。
- **处理目的：** 查询、核验、恢复和管理会员权益。
- **处理方式：** 服务器记录和计算权益状态，向已登录的用户返回其对应的会员信息。
- **存储位置：** 我们的业务服务器；应用本地可能缓存必要的展示状态。
- **是否必要：** 使用账号会员权益服务时需要。
- **是否上传：** 相关权益记录由业务服务器处理。
- **特别说明：** 会员权益与微信账号关联，不代表私密媒体、计算器密码或应用锁配置会同步。

## 三、第三方 SDK 可能处理的个人信息

### 1. 友盟+移动统计 SDK

- **提供方：** 友盟同欣（北京）科技有限公司。
- **可能处理的信息：** Android ID、OAID、OpenUDID、GUID，设备品牌、型号、系统版本、语言、时区、屏幕参数、IP 地址、网络状态、运营商信息、应用版本、分发渠道、会话和必要的事件信息。
- **处理目的：** 基础运营统计、活跃分析及功能使用情况分析。
- **初始化条件：** 用户同意隐私政策后。
- **是否涉及第三方：** 是。
- **隐私政策：** https://www.umeng.com/page/policy

具体信息种类取决于设备系统、SDK 版本和实际配置。

### 2. 腾讯 Bugly CrashReport SDK

- **提供方：** 深圳市腾讯计算机系统有限公司。
- **可能处理的信息：** 异常堆栈、线程信息、异常发生时间、应用版本、设备品牌、型号、Android 版本、CPU 架构、内存及磁盘状态、网络类型等必要信息。
- **处理目的：** 崩溃、ANR 等异常分析及稳定性改进。
- **初始化条件：** 用户同意隐私政策且已配置有效服务标识。
- **是否涉及第三方：** 是。
- **隐私政策：** https://static.bugly.qq.com/bugly-sdk-privacy-statement.pdf

我们不会主动向 Bugly 附加计算器密码、私密媒体或应用锁配置等业务数据。

### 3. 微信 Open SDK

- **提供方：** 深圳市腾讯计算机系统有限公司。
- **可能处理的信息：** 微信授权所需的应用标识、授权结果及必要的设备或运行环境信息，具体以实际 SDK 版本及微信官方规则为准。
- **处理目的：** 在用户主动选择微信登录时完成授权。
- **初始化或调用条件：** 用户主动使用微信登录功能，并满足必要的隐私同意条件。
- **是否涉及第三方：** 是。
- **隐私政策：** https://privacy.qq.com/

## 四、信息保存及删除

1. **本地业务信息：** 通常保存至你主动删除、清除应用数据或卸载应用时为止。
2. **设备试用信息：** 服务器根据试用资格管理和必要的防重复领取目的保存，达到处理目的或依法应删除时进行删除或匿名化处理。
3. **账号及会话信息：** 在账号服务所需期间保存；无效会话及不再必要的信息按照实际清理规则处理。
4. **会员权益记录：** 根据权益核验、用户权利请求及适用法律要求保存和处理。
5. **第三方 SDK 信息：** 由对应提供方按照其隐私规则和适用法律处理。

你可以通过应用内功能管理本地数据，或发送邮件至 594841675@qq.com 申请依法查阅、删除、注销账号等。

账号注销不等于清除本地私密数据，也不等于注销微信平台账号。应用内账号注销功能将在后续版本提供；当前可通过邮件提出申请。

- 设备试用资格与微信账号会员权益分别管理。

- 如后续新增支付、云同步或其他个人信息处理功能，我们将依法更新本清单及相关隐私说明。
