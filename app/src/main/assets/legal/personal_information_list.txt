一、清单说明

本清单用于说明“应用加密计算器”在提供功能和服务过程中处理的个人信息种类、处理目的、处理方式、存储位置及必要性。

本清单与《应用加密计算器隐私政策》共同构成个人信息处理说明。具体功能是否启用，以你实际使用的应用版本为准。此清单说明可能处理的信息范围，实际已收集的信息请参阅《已收集个人信息清单》。

我们遵循最小必要原则，不因使用计算器基础功能而要求你登录微信账号、开启应用锁权限或上传私密媒体。

二、本应用自行处理的个人信息

1. 隐私协议同意记录

- 信息内容： 隐私政策同意状态、协议版本、同意时间。
- 处理目的： 记录用户隐私选择，管理相关功能及 SDK 的初始化条件。
- 处理方式： 在用户作出选择后记录和读取。
- 存储位置： 应用本地专属存储。
- 是否必要： 用于记录用户选择；不同意隐私政策时仍可使用基本计算器功能。
- 是否上传： 不因记录同意状态而主动上传至业务服务器。

2. 计算器隐私空间密码信息

- 信息内容： 密码哈希、随机盐值、哈希算法参数、密码配置状态及创建或更新时间。
- 处理目的： 创建、验证和修改隐私空间密码。
- 处理方式： 在本地计算和验证，不保存明文密码。
- 存储位置： 应用本地专属存储。
- 是否必要： 使用密码保护的隐私空间时需要。
- 是否上传： 不上传。
- 敏感性说明： 相关验证材料一旦泄露可能影响个人隐私安全，我们采取必要保护措施。

计算器输入的算式和计算结果仅用于当前计算过程，不作为长期业务记录保存，也不会上传至服务器。

3. 已安装应用及应用管理信息

- 信息内容： 具有桌面启动入口的应用名称、包名、图标、可用状态；用户主动选择的应用名称快照、包名、排序、最近打开时间和次数等。
- 处理目的： 展示可选应用列表、管理私密应用入口、启动指定应用。
- 处理方式： 读取符合系统查询条件的应用信息；仅持久化用户主动选择的必要配置。
- 存储位置： 当前设备本地。
- 是否必要： 使用应用管理或应用自定义功能时需要。
- 是否上传： 不上传完整应用列表或用户选择的目标应用信息。

4. 自定义快捷入口配置及应用锁配置

- 信息内容： 自定义名称、内置图标配置、快捷入口状态、受保护应用包名、应用锁开关及必要的保护配置。
- 处理目的： 创建自定义快捷入口，识别受保护应用并执行密码验证。
- 处理方式： 本地保存配置；在应用锁运行期间按需判断前台应用状态。
- 存储位置： 当前设备本地。
- 是否必要： 使用对应功能时需要。
- 是否上传： 不上传。

当前应用锁使用“使用情况访问”（PACKAGE_USAGE_STATS）、前台服务和“显示在其他应用上层”（SYSTEM_ALERT_WINDOW）；本版本未接入 Android 无障碍服务。

你主动开启应用锁并授予使用情况访问后，本应用通过 UsageStats 查询近期应用前后台使用事件及包名，必要时查询使用统计中的最近使用时间以判断前台应用。系统接口返回的信息范围受系统实现影响。系统返回的信息可能涉及未被你设为受保护的应用，本应用再在本地判断包名是否属于保护列表。

该识别过程不读取其他应用的界面文本、聊天或密码输入，不保存查询得到的完整使用历史，也不将这些识别结果上传服务器。你主动启动所选应用产生的本地最近打开时间、次数等管理记录，与此处的前台识别过程分别处理。

应用锁开启后，本应用通过前台服务持续执行前台应用识别，显示持续状态通知，并在需要时通过悬浮窗显示本应用的密码验证界面。关闭使用情况访问或悬浮窗能力会影响应用锁保护，不影响不依赖这些能力的基础计算器。

5. 私密相册信息

- 信息内容： 用户主动选择的图片、视频及其文件名称、类型、大小、私有路径、缩略图路径、原始内容 URI、宽高、导入时间、所属文件夹等。
- 处理目的： 导入、保存、查看、整理、删除和恢复私密媒体。
- 处理方式： 通过系统文件或媒体选择器读取用户选定的文件，复制至应用私有目录并建立本地索引。
- 存储位置： 当前设备本地。
- 是否必要： 使用私密相册功能时需要。
- 是否上传： 不上传。
- 敏感性说明： 私密媒体及其管理信息可能属于敏感个人信息。

未经你主动选择并完成系统要求的确认，本应用不会删除系统相册中的原始文件。

6. 设备免费试用信息

- 信息内容： 本地首次使用时间、试用开始时间、到期时间、试用状态、必要的时间校验记录，以及 Android ID（SSAID）。
- 处理目的： 提供符合条件的设备一次免费试用、校验有效期、减少重复领取。具体试用时长以激活试用时的页面展示为准。
- 处理方式： 本地记录试用状态；在用户对当前政策版本作出有效同意后，于试用核验场景读取 Android ID 并通过安全网络连接发送至服务器。首次激活需联网核验。
- 存储位置： 本地试用记录保存在当前设备；服务器保存经过 HMAC-SHA256 处理的设备标识摘要及必要的试用记录。
- 是否必要： 本地试用记录用于提供免费试用；设备标识联网校验用于服务端试用资格管理。
- 是否上传： 试用联网核验时上传原始 Android ID 用于服务器处理；业务数据库不保存原始 Android ID。
- 使用限制： 不用于广告个性化推荐，不用于读取私密媒体或应用锁配置。

Android ID 属于可用于识别或关联设备的信息。即使服务器保存的是摘要，也不意味着该信息必然属于匿名信息。

7. 微信登录与账号信息

- 信息内容： 微信授权返回的一次性授权凭证、微信 OpenID、UnionID（如微信返回）、应用内部用户 ID、账号关联关系、账号创建时间及状态、登录会话凭证及有效期信息。
- 处理目的： 完成微信身份验证、建立账号、维持登录状态及查询、恢复会员权益。
- 处理方式： 用户主动授权后向服务器提交授权凭证；服务器完成身份验证并建立会话；本地加密保存必要会话凭证，服务器保存会话凭证哈希及必要的有效期信息。
- 存储位置： 当前设备及我们的业务服务器。
- 是否必要： 用户主动选择微信登录及使用需登录的会员服务时需要。
- 是否上传： 上传完成登录和会话验证所需的信息。

我们不会因微信登录获取微信昵称、头像、手机号码、聊天记录、通讯录、微信支付密码或本地私密媒体。
为支持忘记密码时的恢复，本机保存经设备密钥（Android Keystore）加密的密码恢复材料；该材料仅用于在计算器页面恢复密码，不上传服务器，卸载或清除应用数据即删除。

8. 会员权益信息

- 信息内容： 应用账号标识、会员套餐、权益来源、生效和到期时间、权益状态及发放、撤销记录。
- 处理目的： 核验会员资格、提供会员服务及恢复有效权益。
- 处理方式： 通过服务端查询和管理权益，本机保存必要的会员状态缓存。
- 存储位置： 当前设备及我们的业务服务器。
- 是否必要： 购买、查询、恢复或使用会员权益时需要。
- 是否上传： 联网提交查询及核验所需的信息。
- 使用限制： 账号权益与设备试用分别管理，不涉及私密媒体、计算器密码或应用锁配置同步。

9. 支付及交易信息

- 信息内容： 应用账号标识、订单编号、购买请求标识、套餐及商品名称、订单金额、币种、支付渠道、支付状态、订单创建及支付等时间、第三方交易编号、实付金额、支付通知摘要、通知来源 IP 地址及必要的订单处理记录。
- 处理目的： 创建订单、确认支付结果、发放会员权益、处理异常交易及售后请求。
- 处理方式： 服务端创建订单并与悦森支付进行必要交互，客户端跳转外部收银台支付；通过支付通知和查单确认交易结果。
- 存储位置： 业务服务器保存必要交易记录，本机保存必要的购买流程记录；支付服务商按其规则处理相关信息。
- 是否必要： 用户主动购买会员及处理相关售后时需要。
- 是否上传： 提交创建订单、查询和确认交易所需信息；向聚合支付服务提供商传递订单编号、商品名称、交易金额、支付方式等必要信息。
- 特别说明： 本应用业务页面不要求输入银行卡号或支付密码，未内置微信支付或支付宝支付 SDK。详细第三方说明见《与第三方共享个人信息清单》。

10. 网络及客服信息

- 信息内容： IP 地址、必要的网络请求信息，以及您主动提供的联系邮箱、订单信息、问题说明和必要的身份核验信息。
- 处理目的： 提供联网服务、接口限流、支付通知处理以及咨询、投诉和售后处理。
- 处理方式： 在联网请求及用户主动联系客服时处理；设备试用请求 IP 用于内存限流，不写入设备试用记录；支付通知来源 IP 随必要交易通知记录保存。
- 存储位置： 服务端、必要的交易记录及客服沟通渠道。
- 是否必要： 提供对应联网服务或处理用户请求时需要。

儿童个人信息处理规则详见《儿童个人信息保护规则》。普通隐私同意不替代依法需要取得的监护人同意。

四、信息保存及删除

1. 本地业务信息： 通常保存至你主动删除、清除应用数据或卸载应用时为止。
2. 设备试用信息： 服务器根据试用资格管理和必要的防重复领取目的保存，达到处理目的或依法应删除时进行删除或匿名化处理。
3. 账号及会话信息： 在账号服务所需期间保存；无效会话及不再必要的信息按照实际清理规则处理。
4. 会员权益记录： 根据权益核验、用户权利请求及适用法律要求保存和处理。
5. 支付及交易信息： 按适用法律法规及处理交易、售后和争议所必要的期限保存。
6. 第三方 SDK 信息： 由对应提供方按照其隐私规则和适用法律处理。

我们的业务服务器部署在中国境内（阿里云成都地域）。依法需要保留的信息在必要期限内限制处理。

你可以通过应用内功能管理本地数据，或发送邮件至 594841675@qq.com 申请依法查阅、删除、注销账号等。

您可以通过「设置—安全—注销账号」注销应用账号。注销成功后删除微信绑定及登录会话，停用原账号、终止会员权益并清除本机账号及会员缓存；依法保留必要交易记录及关联信息。设备试用记录及本地隐私数据不因注销而改变。账号注销不等于注销微信平台账号，再次使用同一微信登录将创建新账号，不恢复原会员权益。您也可通过「设置—隐私协议」撤回隐私同意。
