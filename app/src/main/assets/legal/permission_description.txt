一、当前功能与权限原则

本说明以当前 Android 实现及 Release Manifest 为准。当前应用锁使用 UsageStats 使用情况访问、specialUse 前台服务和悬浮窗；本版本未接入无障碍服务。

权限按实际功能使用，拒绝不相关权限不影响基础计算器。需要有效隐私同意的 SDK 或设备试用上传，还须通过当前政策版本的有效同意门禁；声明普通权限不代表已取得隐私同意。

设备试用标识上传默认关闭。服务端已实现会员权益接口，Android 真实会员查询和恢复尚未正式启用；在线支付尚未上线，不接入支付 SDK，不生成支付结算订单。

二、当前权限及系统能力

1. 网络访问：android.permission.INTERNET

用于用户主动微信登录、会话校验/退出，以及在开关启用且有效同意后进行设备试用联网校验；统计和异常 SDK 仅在有效同意后使用网络。Android 普通权限，不弹单独运行时授权。网络失败不影响基础离线计算器；当前不以此权限进行真实会员查询或支付。

2. 网络状态：android.permission.ACCESS_NETWORK_STATE

用于观察网络连接和恢复，触发符合开关与隐私门禁条件的同步。普通权限；网络恢复不绕过有效同意。

3. Wi-Fi 状态：android.permission.ACCESS_WIFI_STATE

用于联网环境信息及统计 SDK 可能需要的 Wi-Fi 连接状态。当前业务不以此读取 Wi-Fi 密码；具体 SDK 处理范围见第三方 SDK 目录。

4. 使用情况访问：android.permission.PACKAGE_USAGE_STATS

应用锁前台识别的当前实现。需用户在系统“使用情况访问”中主动允许；Manifest 声明本身不能直接授予此特殊访问。

应用锁运行期间约每 250 毫秒查询最近约 5 秒的前后台应用使用事件、事件类型及包名；必要时使用 UsageStats 的最近使用时间回退判断。系统接口回退结果范围受系统实现影响，可能涉及未加入保护列表的应用，不保证系统只返回受保护应用的信息。本应用再将判断出的包名与本地保护列表比对。

此过程不读取其他应用的界面文本、聊天或密码输入，不保存完整查询历史，不上传识别结果。主动启动所选应用的本地最近打开记录、次数另属应用管理配置。拒绝或关闭使用情况访问后，自动识别及应用锁保护会受影响；不影响基础计算器。

5. 显示在其他应用上层：android.permission.SYSTEM_ALERT_WINDOW

需用户在系统特殊访问设置中允许；在受保护应用前显示本应用的密码验证界面。不用于读取其他应用输入或展示无关广告。关闭后无法正常提供依赖悬浮窗的应用锁验证界面。

6. 应用锁前台服务：android.permission.FOREGROUND_SERVICE、android.permission.FOREGROUND_SERVICE_SPECIAL_USE

AppLockMonitorService 声明 foregroundServiceType="specialUse"，用途说明为 app_lock_foreground_monitor。应用锁开启、必要条件满足时，服务持续轮询前台应用状态，结合本地保护列表触发验证，并建立低打扰的持续状态通知。不用于定位、录音、媒体扫描或试用后台上传任务。

这两项为服务运行声明，不替代使用情况访问、悬浮窗授权或隐私同意。关闭保护或撤回同意会停止相关服务；系统后台限制可能影响运行，声明权限不保证永久后台保活。

7. 通知：android.permission.POST_NOTIFICATIONS

Android 13 及以上，在你主动开启一个应用的应用锁、保存成功且尚未允许通知时，本应用首次说明通知用途；你选择“允许通知”后才发起 POST_NOTIFICATIONS 系统申请。通知仅用于在通知栏展示应用锁前台服务的持续运行状态，低重要性、静默、非营销通知。

你可以暂不申请或拒绝。此时会明确提示可能无法在通知栏看到应用锁运行状态，并提供系统通知设置入口；不因拒绝就认定应用锁或前台服务无法运行，也不影响基础计算器、使用情况访问和悬浮窗授权。前台服务仍遵循系统的通知及任务展示规则。

为避免反复打扰，本地保存一次提示标记（属于应用锁本地设置，不含包名、设备标识或账号，不上传服务器）；仅进入或反复打开应用锁页面不会重复申请。拒绝、跳过或系统不再显示弹窗后，可主动前往系统通知设置管理，不反复自动发起系统申请。授权结果以系统状态为准，本应用不额外持久化通知授权结果。

Android 12 及以下不请求 POST_NOTIFICATIONS；如在系统设置关闭了本应用通知，可通过通知设置入口管理。允许通知后更新应用锁运行通知，不重新配置或暂停原有保护逻辑。

8. 旧系统媒体恢复：android.permission.WRITE_EXTERNAL_STORAGE（maxSdkVersion=29）

仅在 Android 10 及以下实际需要的媒体保存/恢复场景按系统规则请求；拒绝可能影响对应恢复操作。现代系统通过 MediaStore 或系统选择器处理，不申请全盘照片/视频读取权限，也不后台扫描并上传全部媒体。

9. 文件及媒体选择（不等于广泛存储权限）

通过 Android 系统照片或文件选择器处理用户主动选择并授权的图片、视频及必要 URI 信息，用于导入、查看和恢复。不因安装应用获得全部媒体访问权。

10. 应用可见性（queries 声明）

通过 MAIN/LAUNCHER 查询有桌面入口的应用名称、包名、图标及可用状态；另有 com.tencent.mm 包查询以判断微信可用性。不是 QUERY_ALL_PACKAGES 权限，不上传完整应用列表。

11. Android ID（SSAID，通常无需额外危险权限）

本地首次启动只记录时间和试用状态，不为试用读取设备标识。自有试用上传默认关闭；只有联网校验启用且已取得当前版本有效同意后，才可能读取 SSAID 并发送自有服务器，服务器以 HMAC-SHA256 处理并保存必要摘要和试用记录。无效、缺失或异常时安全降级；不用于用户身份认证。

统计 SDK 的设备标识处理与自有试用开关分别控制，见第三方 SDK 目录。关闭自有试用上传不等于禁止有效同意后的所有 SDK 标识处理。

12. 内部广播保护：com.aurora.calculatorvault.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION

AndroidX 合入的应用自定义 signature 权限，用于内部动态广播安全保护，不是额外设备标识访问权限，不要求用户手动授权。

三、已移除的 SDK 合入权限

友盟 Common 9.9.8 原合入 com.google.android.gms.permission.AD_ID 和 freemme.permission.msa。本版本没有广告投放、广告归因或业务厂商标识功能依赖，使用 Manifest 合并移除规则排除这两项，最终 Release 不再请求它们。

不能仅凭原权限存在就断言 SDK 已读取了相应标识，也不能因移除权限就宣称全部 Android 版本、厂商和 SDK 路径都无法处理任何标识。其他可能标识及必要处理条件仍见主隐私政策和 SDK 目录，具体行为需动态核验。

四、权限管理及未接入能力

可在系统“应用—应用加密计算器”中管理权限；使用情况访问和显示在其他应用上层需进入对应专项设置，不同品牌路径不同。本版本没有本应用无障碍服务开关，不应引导用户寻找不存在的服务。

当前不申请位置、麦克风、摄像头、通讯录、短信、通话记录、读取 IMEI 或 QUERY_ALL_PACKAGES 等权限。后续如实际功能变化，应先核对必要性和说明，不因修改文档增加权限。

当前没有年龄分流或可核验的有效监护人同意流程；普通隐私同意不代表监护人同意，相关儿童保护措施仍需后续产品落实。
