一、适用范围和服务内容

本政策适用于本应用提供的计算器、密码保护的隐私空间、私密应用入口管理、应用锁、应用伪装快捷入口、私密相册、设备免费试用、微信登录、会员相关展示和设置等功能。

部分功能可能根据应用版本、设备兼容情况和服务开通进度逐步提供，具体以你实际使用的版本为准。

本应用的计算器输入内容仅在当前运行过程中用于完成计算，不会保存到业务数据库，也不会上传至我们的服务器。

本应用的计算器密码与微信登录账号相互独立。微信登录不会替代计算器密码验证，也不会使我们获得读取、恢复你本地计算器密码的能力。

当前本应用不提供私密媒体云同步或在线密码找回服务。私密照片、视频及应用锁配置原则上仅保存在当前设备。

二、我们如何处理个人信息

我们遵循合法、正当、必要和诚信原则，仅在实现明确功能所需的范围内处理个人信息。

1. 隐私同意和密码安全信息

当你同意本政策并创建隐私空间密码时，我们会在本机保存隐私同意状态、协议版本、同意时间，以及密码哈希、随机盐值、哈希算法参数、密码配置状态和创建或更新时间，用于记录你的选择并在本机验证密码。

计算器密码不会以明文保存，也不会上传至我们的服务器。

上述密码验证材料属于一旦泄露可能影响个人隐私及安全的敏感个人信息。我们仅在你主动创建或修改密码时处理，并将其保存在应用专属本地存储中。

2. 应用管理、应用伪装和应用锁信息

当你主动使用相关功能时，我们会读取设备上具有桌面启动入口的应用名称、包名、图标和可用状态，供你选择目标应用。

完整扫描结果仅用于当次列表展示，不会整体上传或持久化。

对于你主动选择的应用，我们会在本机保存应用包名、应用名称快照、排序、最近打开时间和次数、伪装名称、内置图标配置、快捷入口状态以及应用锁开关等必要信息，用于展示列表、启动入口和执行你选择的保护设置。

上述信息不会上传至我们的服务器或主动提供给第三方 SDK。

当前应用锁使用“使用情况访问”（PACKAGE_USAGE_STATS）、前台服务和“显示在其他应用上层”（SYSTEM_ALERT_WINDOW）；本版本未接入 Android 无障碍服务。

你主动开启应用锁并授予使用情况访问后，本应用通过 UsageStats 查询近期应用前后台使用事件及包名，必要时查询使用统计中的最近使用时间以判断前台应用。当前轮询间隔约为 250 毫秒，事件查询窗口约为最近 5 秒；统计回退接口返回范围受系统实现影响。系统返回的信息可能涉及未被你设为受保护的应用，本应用再在本地判断包名是否属于保护列表，不宣称系统只返回受保护应用的信息。

该识别过程不读取其他应用的界面文本、聊天或密码输入，不保存查询得到的完整使用历史，也不将这些识别结果上传服务器。你主动启动所选应用产生的本地最近打开时间、次数等管理记录，与此处的前台识别过程分别处理。

应用锁开启后，AppLockMonitorService 以 specialUse 类型前台服务持续执行前台应用识别，显示持续状态通知，并在需要时通过悬浮窗显示本应用的密码验证界面。关闭使用情况访问或悬浮窗能力会影响应用锁保护，不影响不依赖这些能力的基础计算器。

3. 私密相册信息

当你通过 Android 系统文件或媒体选择器主动选择图片、视频时，本应用会读取你选择的文件，并将副本保存到应用私有目录，同时在本机数据库保存媒体名称、媒体类型、大小、私有文件路径、缩略图路径、原始内容 URI、宽高、导入时间和所属文件夹等管理信息。

私密图片、视频及其管理信息可能反映个人私密活动，属于敏感个人信息。

我们仅在你主动导入、查看、恢复、删除或整理媒体时处理相关信息。

除非你明确选择“从系统相册移除原文件”并完成系统确认，否则本应用不会主动删除原文件。

本应用不会将私密媒体及其管理信息上传至我们的服务器，也不会因微信登录自动同步这些内容。

4. 设备标识与 72 小时免费试用管理

为提供每台设备一次、连续 72 小时的免费试用服务，记录试用资格并减少重复领取，我们会在本应用首次启动时于本地记录首次使用时间、试用有效期及必要的试用状态。

在你同意本政策且设备试用联网校验功能已启用后，本应用可能读取设备的 Android ID（SSAID），作为应用范围内的设备识别信息，并通过安全的网络连接发送至我们的服务器。

服务器使用 HMAC-SHA256 对设备标识进行处理，保存处理后的标识摘要及对应的试用开始时间、到期时间和必要状态信息，不在业务数据库中保存原始 Android ID。

上述信息仅用于设备试用资格管理、试用有效期校验及减少重复领取试用，不用于广告个性化推荐，也不会用于读取你的私密相册、计算器密码或应用锁配置。

当网络不可用时，本应用可以根据本地保存的试用记录判断试用状态；恢复联网后，可能与服务器核对试用资格和有效期。

Android ID 可能因设备、系统用户、应用签名或系统状态变化而改变，因此我们无法保证在所有情况下准确识别同一物理设备。

未同意本政策时，本应用不会为设备试用校验向服务器发送 Android ID。

5. 微信登录与账号管理

当你主动选择微信登录时，本应用会通过微信开放平台提供的授权能力完成登录。

在获得你的授权后，本应用会取得微信授权返回的一次性授权凭证，并将其提交至我们的服务器进行身份验证。

为建立和维护应用账号，我们可能处理：

（1）微信开放平台提供的必要账号标识，例如 OpenID；

（2）应用内部生成的用户标识；

（3）登录授权结果、会话凭证及其校验信息；

（4）账号创建时间、必要的登录状态和会话有效期信息。

我们不会因你使用微信登录而自动获取你的微信聊天记录、通讯录、微信支付密码或其他与登录无关的信息。

本应用会通过 Android Keystore 支持的加密机制保护本地会话凭证，服务器保存用于验证登录会话的必要记录。

微信登录为可选择功能。你可以暂不登录，继续使用不要求账号登录的功能。

退出登录后，当前设备将停止使用该账号的登录权益，但不会因此删除本地私密照片、视频、计算器密码或应用锁配置。

服务端已具备按账号查询有效会员权益的接口；当前 Android 尚未完成真实会员查询及恢复联调，登录不代表已经恢复真实会员权益，也不会自动同步原设备的私密数据。

6. 会员权益信息

AuroraAppServer 已实现会员权益接口，可按应用及账号处理用户标识、套餐、权益来源、开通和到期时间、权益状态、发放及撤销记录，用于服务端权益管理与核验。

当前 Android 端仅有套餐、账号及会员相关展示，尚未正式启用真实会员查询和恢复，也不会为展示套餐自动向会员接口提交查询或建立真实权益缓存。月度、年度、永久会员等套餐展示不代表已经开通会员。

后续正式接入后，账号会员权益按对应应用账号管理，可依据服务器有效记录查询或恢复；当前版本不承诺已能跨设备恢复。设备试用与账号权益独立，退出微信登录不重置设备试用。

在线支付尚未上线，当前不接入支付 SDK，不生成支付订单或收集支付结算交易流水，也不会因点击套餐或免费试用自动扣款。正式上线购买、退款等服务前，将补充真实服务商、订单、交易回调及退款处理说明并履行必要告知。

7. 统计分析信息

在你已对当前政策版本作出有效同意后，本应用会初始化友盟+移动统计 SDK，用于统计应用启动、活跃会话和少量核心功能入口点击。

该 SDK 可能通过自动化方式处理：

（1）设备标识信息：Android ID、OAID、OpenUDID、GUID，具体项目因设备系统和 SDK 配置而异；

（2）设备及系统信息：设备品牌、型号、制造商、操作系统版本、语言、时区、屏幕参数等；

（3）网络信息：IP 地址、网络类型、Wi-Fi 联网状态、运营商信息等；

（4）应用及使用信息：应用包名、版本、分发渠道、SDK 版本、启动时间、会话信息和不含业务参数的自定义事件 ID。

用途是进行基础运营统计、分析核心功能使用率和改进产品稳定性。

当前自定义事件不携带计算器密码、目标应用信息、私密媒体、文件夹名称或计算器输入等业务内容。

未同意本政策时，不初始化该 SDK，也不上报自定义事件。

当前版本的 SDK 权限与标识边界：友盟 Common 9.9.8 原合入的 com.google.android.gms.permission.AD_ID、freemme.permission.msa 已通过 Manifest 合并规则移除；当前没有广告投放/归因或业务厂商标识功能依赖。权限声明不能证明实际采集，权限移除也不能证明所有系统和 SDK 路径均不处理标识。友盟可能按设备、系统及配置处理 Android ID、OAID、OpenUDID、GUID 等信息，仅在当前政策版本有效同意后初始化；实际范围需动态核验。自有设备试用上传默认关闭，该开关不等同于 SDK 的全部标识开关。

8. 异常监控信息

在你同意本政策且应用配置了正式服务标识后，本应用会初始化腾讯 Bugly CrashReport SDK。

应用发生 Crash、ANR、Native Crash 或未捕获 OOM 等异常时，该 SDK 可能自动处理异常类型、异常堆栈、线程和发生时间，应用包名、版本、进程名、进程 ID，以及设备品牌、型号、Android 版本、API Level、CPU 架构、Root 状态、磁盘或内存使用情况、网络类型等必要运行环境信息，用于定位和修复稳定性问题。

我们未主动向 Bugly 设置自定义用户 ID、设备唯一 ID、自定义用户数据、业务日志或附件，并关闭 Bugly 自定义日志上传。

我们不会主动附加密码、目标应用信息、媒体 URI、媒体名称、私密文件路径、文件夹名称或计算器输入内容。

未同意本政策、主动拒绝或缺少正式 Bugly App ID 时，不初始化该 SDK。

三、权限和系统能力

本应用仅在相应功能场景使用必要的权限和系统能力，不会因你拒绝非基本功能所需权限而影响计算器等不依赖该权限的功能。

根据 Android 版本及实际功能，本应用可能使用：

（1）网络访问权限（INTERNET）：用于微信登录、会话维护、符合门禁的设备试用校验及必要的统计/异常监控通信；当前 Android 真实会员查询尚未正式启用；

（2）网络和 Wi-Fi 状态：用于判断网络连接状态；

（3）使用情况访问（PACKAGE_USAGE_STATS）：主动授权后查询近期应用使用事件及包名、必要的最近使用时间，再在本地筛选受保护应用；本版本未使用无障碍服务；

（4）显示在其他应用上层（SYSTEM_ALERT_WINDOW）：用于在受保护应用前显示本应用的密码验证界面；

（5）应用内部签名权限 com.aurora.calculatorvault.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION：用于 AndroidX 内部动态广播安全保护，不用于收集设备信息；

（6）FOREGROUND_SERVICE、FOREGROUND_SERVICE_SPECIAL_USE：应用锁启用时维持 specialUse 前台应用识别服务及其状态通知；

（7）POST_NOTIFICATIONS：Android 13 及以上由用户决定是否允许展示应用锁前台服务通知；拒绝后系统通知展示受限，不等同于授予或撤回使用情况访问和悬浮窗权限；

（8）Android 10 及以下的外部存储写入权限：仅在相应系统版本和功能场景需要时使用；

（9）设备应用可见性：通过 Android 的 MAIN/LAUNCHER 查询声明，获取供你选择的应用列表。

本应用不因设备试用而申请 IMEI、MAC 地址或设备序列号等受限制的硬件标识访问权限。

Android ID 的读取通常不需要额外申请危险权限。

你可以在系统“设置—应用—应用加密计算器—权限”或对应的特殊权限设置中查看、管理或撤回授权。

撤回权限后，我们将停止通过该权限继续处理信息，但依赖该权限的相应功能可能无法正常使用。

具体权限、用途及触发时机详见《应用权限说明》。

五、信息存储期限和地点

1. 本地业务数据

计算器密码验证材料、应用管理记录、私密媒体及其索引、应用锁配置等主要保存在你的当前设备中。

上述数据通常保存至你在应用内删除相关内容，或通过系统清除应用数据、卸载应用时为止。

设备应用扫描结果仅在完成当次展示所需的短时间内处理。

本地设备试用状态经 Android Keystore 支持的加密保存在不参与备份的应用专属存储中，用于连续计时和恢复；Android ID 原始值不在普通 SharedPreferences 中保存。当前设备试用标识上传默认关闭，仅在联网校验启用且已取得当前版本有效同意后才可能读取并上传。

2. 服务器业务数据

为提供设备试用、微信登录和会员权益服务，我们的服务器可能保存：

（1）设备标识摘要及试用记录；

（2）应用内用户标识及微信账号关联信息；

（3）登录会话校验记录及有效期；

（4）会员套餐、权益发放、到期及撤销记录。

上述信息仅在实现相应服务、处理用户请求及履行适用法律义务所必要的期限内保存。

对于依法需要删除或匿名化的信息，我们将在核实请求及适用条件后处理；依法需要保留的记录将在必要期限内限制使用。

3. 第三方数据

友盟、Bugly 和微信相关服务处理的信息，由相应服务提供方依据其个人信息处理规则保存和管理。

你可以通过本政策列明的联系方式向我们提出相关请求，我们将依法处理或协助联系相关服务提供方。

4. 存储地点

本应用的本地业务数据保存在你的设备中。

我们当前不会主动安排将个人信息传输至中华人民共和国境外。如未来发生跨境提供，我们将依法履行必要的告知、同意及安全保障义务。

自有服务端的具体部署地点和数据处理安排，以实际运营配置为准，并应在正式提供相关联网服务前完成必要披露。

六、信息安全保护

我们采取与处理风险相适应的技术和管理措施保护个人信息，包括：

（1）应用私有目录和 Android 系统沙箱隔离；

（2）计算器密码加盐哈希处理；

（3）Android Keystore 支持的本地会话及必要业务状态加密；
