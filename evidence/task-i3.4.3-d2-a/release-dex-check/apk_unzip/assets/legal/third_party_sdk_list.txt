 一、说明

为了实现应用统计、异常监控和微信授权登录等功能，本应用可能接入第三方软件开发工具包（SDK）。

第三方 SDK 可能依据其功能需要处理必要的设备、应用运行及授权信息。我们会根据实际功能需要控制 SDK 的接入、调用及初始化时机，并按照适用法律法规履行告知和个人信息保护义务。

本目录列明本应用当前集成的第三方 SDK。具体处理行为可能因应用版本、Android 系统版本、设备环境和 SDK 配置而存在差异。

 二、第三方 SDK 明细

 1. 友盟+移动统计 SDK

SDK 名称： 友盟+移动统计 SDK
提供方： 友盟同欣（北京）科技有限公司
SDK 版本： Common 9.9.8、ASMS 1.8.7.2
使用目的： 统计应用启动、活跃会话、基础使用情况及部分功能入口事件，辅助分析产品使用情况和改进服务。

可能处理的个人信息：

- 设备标识信息：Android ID、OAID、OpenUDID、GUID 等；
- 设备信息：品牌、型号、制造商、操作系统版本、语言、时区、屏幕参数；
- 网络信息：IP 地址、网络类型、Wi-Fi 联网状态、运营商信息；
- 应用运行信息：应用包名、版本、分发渠道、SDK 版本、启动时间、会话信息；
- 统计事件信息：本应用主动配置的、不包含敏感业务参数的事件标识。

处理方式： SDK 根据配置在应用运行期间采集必要信息，并可能通过网络发送至其服务端进行统计处理。

初始化条件： 用户对当前政策版本作出有效同意后。

我们采取的限制措施： 不主动通过自定义事件上传计算器密码、计算内容、私密媒体、目标应用包名、文件夹名称等敏感业务内容。

官方隐私政策：
https://www.umeng.com/page/policy

当前版本的 SDK 权限与标识边界：友盟 Common 9.9.8 原合入的 com.google.android.gms.permission.AD_ID、freemme.permission.msa 已通过 Manifest 合并规则移除；当前没有广告投放/归因或业务厂商标识功能依赖。权限声明不能证明实际采集，权限移除也不能证明所有系统和 SDK 路径均不处理标识。友盟可能按设备、系统及配置处理 Android ID、OAID、OpenUDID、GUID 等信息，仅在当前政策版本有效同意后初始化；实际范围需动态核验。自有设备试用上传默认关闭，该开关不等同于 SDK 的全部标识开关。

 2. 腾讯 Bugly CrashReport SDK

SDK 名称： 腾讯 Bugly CrashReport SDK
提供方： 深圳市腾讯计算机系统有限公司
SDK 版本： 4.1.9.3
使用目的： 监控应用崩溃、ANR 和其他异常，定位并修复稳定性问题。

可能处理的个人信息：

- 异常信息：崩溃类型、异常堆栈、线程状态、异常发生时间；
- 应用信息：包名、版本、进程名、进程 ID；
- 设备信息：品牌、型号、Android 版本、API Level、CPU 架构、Root 状态；
- 运行环境信息：内存、磁盘状态、网络类型等。

处理方式： 在发生异常或执行必要的异常监控任务时收集运行信息，并可能通过网络向服务端发送异常报告。

初始化条件： 用户对当前政策版本作出有效同意，且应用配置了有效的 Bugly 服务标识。

我们采取的限制措施： 不主动设置自定义用户 ID、设备唯一 ID、业务附件或包含私密内容的自定义日志；不主动上传计算器密码、私密媒体和应用锁配置。

官方个人信息保护规则：
https://static.bugly.qq.com/bugly-sdk-privacy-statement.pdf

 3. 微信 Open SDK

SDK 名称： 微信 Open SDK（Android）
提供方： 深圳市腾讯计算机系统有限公司
SDK 版本： 微信 Open SDK Android 6.8.40。
使用目的： 用户主动选择微信登录时，调用微信授权能力完成账号身份验证。

可能处理的个人信息：

- 应用标识及授权请求信息；
- 微信授权结果、一次性授权凭证；
- 为实现授权交互所需的必要设备及运行环境信息，具体范围以 SDK 实际行为和微信官方规则为准。

处理方式： 用户主动发起微信登录后，通过微信客户端及相关授权接口完成授权交互。本应用将授权返回的一次性凭证提交至自有服务器，服务器完成身份验证及应用账号会话建立。

调用条件： 用户主动选择微信登录，且满足必要的隐私同意条件。

特别说明： 本应用不会因微信登录主动读取微信聊天记录、通讯录或微信支付密码。微信授权不代表用户授权我们读取本地私密媒体。

微信隐私保护相关说明：
https://privacy.qq.com/

当前能力说明：应用锁使用 UsageStats 使用情况访问、specialUse 前台服务及悬浮窗，未接入无障碍服务。系统近期使用事件及包名可能包括未受保护的应用，由本应用再在本地比对保护列表；具体范围见应用权限说明。服务端会员权益接口已实现，Android 真实会员查询和恢复尚未正式启用；在线支付尚未上线。当前没有年龄分流或可核验的有效监护人同意机制，相关产品措施待后续落实，普通同意不能视为已取得监护人同意。

 三、SDK 的管理原则

1. 我们仅为实现明确的应用功能接入必要 SDK，不会以与服务无关的目的主动调用 SDK。
2. 对于需要取得用户同意后才能处理个人信息的 SDK，我们会在取得相应同意后初始化或调用。
3. 我们会根据应用版本更新、SDK 升级及实际处理行为，适时调整本目录。
4. SDK 提供方可能根据其隐私规则独立处理必要信息。具体处理范围、保存期限及用户权利行使方式，可查阅对应官方隐私规则。
5. 本应用的自有服务器并非第三方 SDK。设备试用、账号会话及会员权益的数据处理情况，详见《应用加密计算器隐私政策》和《个人信息收集清单》。

 四、未来功能与 SDK 变更

当前目录不将尚未实际接入的支付 SDK、广告 SDK 或其他未来服务列为已使用 SDK。

如后续上线在线支付、广告投放、云同步或其他需要新增 SDK 的功能，我们将根据实际接入情况更新本目录，并依法履行告知及必要的同意程序。
